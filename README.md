# New Year Countdown ⏳

A simple countdown timer that shows how much time is left until the New Year, built with HTML, CSS, and JavaScript.

## Features
- Live countdown (Days, Hours, Minutes, Seconds)
- Clean and responsive UI
- Loading spinner animation

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run
1. Clone this repository
```bash
   git clone https://github.com/sanji24096/new-year-countdown.git
```
2. Open `index.html` in your browser
